# MingCute Icons Mapping

Use this mapping table to switch quickly from another icon library to MingCute. Find the source icon, then replace the import with the corresponding MingCute name. Regular and Filled share that name; only the style path changes. MingCute Icons and MingCute Pro also use the same icon names.

The table is not limited to Lucide. Each row maps one source-library icon to a MingCute icon. Add later libraries in the same format, and do not rewrite existing records.

## How to switch with this document

Search this document directly. No separate spreadsheet is required. In the full mapping for the source library, find the source icon. If the status is `Mapped`, use the MingCute name on the right. `Unmapped` or `—` means it cannot be replaced directly yet.

Example: searching for Lucide `activity` gives the MingCute name `heartbeat`. In React, import `@mingcute/react/core-regular/heartbeat`.

When adding another icon library, add its statistics and full mapping to this document. Do not rewrite records from an existing source library. Use these columns:

| Field | Description |
| --- | --- |
| No. | Order within that source library. Number each new library separately |
| Source icon | Icon name in the source library |
| MingCute | Corresponding MingCute icon name. Use `—` when unmapped |
| Status | `Mapped` or `Unmapped` |
